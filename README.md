# Zoro VST Viewer 2.5.0 for Windows x64

Downloads:
- `ZoroVSTViewer-2.5.0-Setup-win64.exe`: graphical installer; installs the Microsoft Visual C++ runtime prerequisite.
- `ZoroVSTViewer-2.5.0-win64-portable.zip`: portable application folder with the runtime installer.

SHA-256 checksums are in `SHA256SUMS.txt`.

This distribution contains executable binaries only; it does not include project source code.
